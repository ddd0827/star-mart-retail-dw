

## 1. 交易与经营指标

### 有效支付订单

存在成功支付记录（`payment_status = '成功'` 且 `pay_amount > 0`）、未被取消、`is_paid = 1` 的订单。

### GMV

有效支付订单的实付金额（`paid_amount`，含运费）之和。

- 归集日期：订单业务日期（本项目支付日与订单日一致；生产环境建议切换为支付日口径）。
- **不扣减退款**。
- 不包含取消订单、失败支付、已失效订单。

### 净销售额

`净销售额 = 期间 GMV − 期间退款额（按退款发生日归集）`

- 日级净销售额允许为负。
- 退款按退款日期进入当期，不回写原销售日。

### 退款额、退款率

- 退款额：`refund_status = '已完成'` 的退款金额之和，按退款日归集。
- 退款率（金额口径）：`退款额 / GMV`。
- 退款订单率：`发生完成的退款订单数 / 有效支付订单数`。
- 处理中的退款不计入退款额，但会在退款流水中保留状态。

### 订单量、客单价

- 订单量：有效支付订单数。
- 客单价（AOV）：`GMV / 有效支付订单数`。

### 会员销售占比

`会员订单 GMV / 全部 GMV`。会员订单指 `is_member = 1` 的有效支付订单；游客/未知会员不计入分子。

### 线上销售占比

`线上渠道 GMV / 全部 GMV`。线上渠道包括微信小程序、APP、第三方平台；线下 POS 为线下。

### 毛利与毛利率

- 商品销售额：订单行 `line_amount` 之和（不含运费）。
- COGS：订单行 `cost_amount` 之和（数量 × 单位成本）。
- 毛利 = 商品销售额 − COGS。
- 毛利率 = 毛利 / 商品销售额。
- 注意：该口径不含运费、未扣退款，属于商品维度毛利率；GMV 与商品销售额分母不同，不能混用。

### 折扣率

`折扣金额 / (商品销售额 + 折扣金额)`。折扣金额来自订单行优惠（活动、会员、随机优惠），不含退款。

## 2. 门店与目标

### 门店客流与转化率

- 线下转化率 = `有效支付订单数 / 门店客流`，只对 `is_offline = 1` 的门店计算。
- 线上仓没有客流，转化率为空。

### 门店月度目标达成率

- 目标表为全月目标金额。
- MTD 目标 = `月度目标 × 数据窗口内已过天数 / 当月天数`。
- 对数据窗口不完整的月份（4 月从 20 日开始、10 月到 16 日结束），按窗口内实际覆盖天数折算，避免达成绩效失真。
- MTD 达成率 = `MTD GMV / MTD 目标`。
- 目标生成时按窗口内日均销售外推到整月，因此完整窗口的达成率通常在 90%–110% 附近波动。

## 3. 会员指标

### RFM

- 快照日：数据结束日（`end_date`）。
- 仅统计至少有一次有效支付且有有效 `member_id` 的会员；未购会员不进入 RFM 表。
- R（Recency）：`快照日 − 最近一次有效支付订单日期`（天）。
- F（Frequency）：有效支付订单数。
- M（Monetary）：`累计 GMV − 累计已完成退款`，下限为 0。
- 打分：对 R/F/M 分别做 `NTILE(5)` 分位打分（1–5 分）；R 越小越好，因此按 R 降序分箱使最近购买者得 5 分；F/M 越大越好，按升序分箱使高价值者得 5 分。
- 客群：以 4 分为“高”的阈值，组合成标准 8 大客群：

| R | F | M | 客群 |
|---|---|---|---|
| 高 | 高 | 高 | 重要价值客户 |
| 低 | 高 | 高 | 重要保持客户 |
| 高 | 低 | 高 | 重要发展客户 |
| 低 | 低 | 高 | 重要挽留客户 |
| 高 | 高 | 低 | 一般价值客户 |
| 低 | 高 | 低 | 一般保持客户 |
| 高 | 低 | 低 | 一般发展客户 |
| 低 | 低 | 低 | 一般挽留客户 |

- 建议动作仅作为运营参考，不代表因果效果。

### 会员留存（Cohort）

- 首购月：会员在数据窗口内第一次有效支付所在月份。
- 月偏移：首购月之后第 N 个月（0–5）。
- 留存人数：在对应月份至少有一次有效支付的该 cohort 会员数。
- 留存率 = 留存人数 / cohort 规模。
- `is_observed` 表示该月是否已进入数据范围；`is_complete` 表示该月是否被数据窗口完整覆盖。4 月、10 月为部分月份，标记为不完整。

### 月度复购

- 月度购买会员：当月至少一次有效支付的会员。
- 月度复购会员：当月有效支付订单数 ≥ 2 的会员。
- 月度复购率 = 复购会员 / 当月购买会员。
- 30 日复购：当月第二次及以后订单中，距当月首单 ≤ 30 天的会员数；30 日复购率 = 该人数 / 当月购买会员。
- 10 月为不完整月份，`is_complete = 0`，看板/报表应区别解读。

## 4. 线上漏斗

- 会话粒度：`session_id`。
- 阶段：访问 → 浏览商品 → 加入购物车 → 进入结算 → 支付成功。
- 每个阶段使用“会话是否到达过该阶段”的标记，并保证单调：
  - 支付 ⇒ 结算 ⇒ 加购 ⇒ 访问；
  - 搜索独立，不影响漏斗单调性（浏览口径包含搜索会话）。
- 支付会话数必须等于线上有效支付订单数（质量规则强制）。
- 转化率：
  - 访问→浏览 = 浏览会话 / 访问会话；
  - 访问→加购、购物车→结算、结算→支付、访问→支付同理。
- 漏斗口径是会话级，不等同于人数级转化；会员/游客会话均计入。

## 5. 库存指标

### 库存周转天数

- 统计窗口：最近 30 天（含当日）。
- 平均库存金额 = 30 天日末库存金额的算术平均。
- 30 日 COGS = 30 天商品销售成本之和。
- 周转天数 = `平均库存金额 / 30日 COGS × 30`。
- 当可用历史不足 30 天或 COGS = 0 时，周转天数为空，不使用不完整窗口冒充 30 日结果。
- 门店与线上履约仓分别计算。

### 缺货率（30 日）

`30 日内期末库存为 0 的 SKU-日数 / 全部铺货 SKU-日数`。

### 售罄率（30 日）

`30 日销售数量 / 30 日可售数量（期初 + 采购入库）`。

## 6. 促销效果（观察性）

- 活动日均 GMV：活动覆盖日期内，该渠道的日均总 GMV。
- 基线日均 GMV：活动开始前 14 天，同渠道日均总 GMV（数据窗口不足 14 天时按实际可用天数，并在基线天数字段体现）。
- 提升率 = `活动日均 / 基线日均 − 1`。
- 增量 GMV = `(活动日均 − 基线日均) × 活动天数`。
- 让利额：活动归因订单的折扣金额之和。
- 基线毛利率：基线期商品毛利率。
- 增量毛利 = 增量 GMV × 基线毛利率。
- ROI = 增量毛利 / 活动让利额。
- **重要说明**：这是活动前后对比的观察性指标，不是因果推断；基线期可能受其他活动、季节、天气、舆情影响，不能将全部增量归因于单一活动。

## 7. 数据质量与对账

以下关系必须成立（严重规则失败会阻断调度）：

1. 有效订单 `paid_amount` = 成功支付金额之和。
2. 订单行金额之和 + 运费 = 订单实付金额。
3. 退款金额 ≤ 对应订单行实付金额。
4. 线上支付会话数 = 线上有效支付订单数。
5. 线下订单数 ≤ 门店客流。
6. 库存：`期初 + 入库 − 销售 + 退货 + 调整 = 期末`，且期末 ≥ 0。
7. DWS 门店日 GMV = DWD 按门店/日重算。
8. ADS 经营总览 GMV = DWS 按日重算。
9. 各事实表主键唯一。

报告位置：`output/quality/dq_report_latest.csv`。

## 8. 口径限制

- 数据窗口末期存在退款右删失：临近结束日的订单可能尚未退款，导致末期退款率偏低。
- 促销 ROI 是观察性对比，不能作为因果结论。
- 线上漏斗是会话级；同一会员一天内可产生多个会话。
- 门店目标由模拟经营规模外推生成，目标达成率用于演示排名与看板，不代表真实绩效。
